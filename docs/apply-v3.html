Design Thinking ⑤ Test

MVP로 검증할 세 가지 가설

가설 01
자연어 질문만으로 고객 데이터를 탐색할 수 있다면 분석 업무 시간이 줄어든다
기존 · Dashboard → 데이터 추출 → 연결 → 분석
Agent · Question → Insight
가설 02
여러 채널의 고객 행동을 연결하면 개별 데이터에서는 보이지 않던 니즈를 발견할 수 있다
단순 검색량이 아니라 검색 전후 앱 탐색, 상품 이용 상태, 상담 행동까지 연결하여 행동의 맥락을 파악합니다.
가설 03
Insight를 실제 업무 Action으로 연결하면 Agent의 실무 활용 가치가 높아진다
분석 결과를 읽고 다시 운영 시스템으로 이동하는 것이 아니라, Agent가 실행 가능한 Action을 제안하고 수행합니다.
